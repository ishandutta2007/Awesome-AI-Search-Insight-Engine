### 📌 Overview & SEO Summary

Welcome to the definitive curated directory of **AI search and insight engines**, **open-source semantic retrieval systems**, **vector databases**, and **RAG-powered knowledge discovery platforms**. As modern enterprises transition from basic keyword indexing to neural retrieval, organizations require robust hybrid search capabilities that combine lexical BM25 precision with dense vector semantic context.

Whether you are seeking enterprise-grade commercial solutions (such as *Glean*, *Coveo*, and *Sinequa*), developer-friendly search APIs (such as *Algolia NeuralSearch* and *Elastic Enterprise Search*), or privacy-preserving self-hosted open-source platforms (such as *Open WebUI*, *Meilisearch*, *Dify*, *RAGFlow*, *Turing*, and *Onyx*), this comprehensive index maps the market leaders, starting prices, free tier allowances, valuation benchmarks, and star-ranked open-source projects.

#### 🗝️ Key Market Context & Industry Insights:
- 🎯 **Glean** is the **most advanced AI enterprise search and insight engine**, featuring **100+ native connectors**, **permissions-aware knowledge graphs**, and **agentic RAG workflows** — serving enterprises like **Databricks, Reddit, Duolingo, and Canvas**.
- 🏛️ **Turing (Viglet)** provides a **complete open-source enterprise search suite**, offering **faceted semantic search, hybrid BM25+vector ranking, RAG chat with citations, AI agents, and Model Context Protocol (MCP) tools** on Apache Solr, Elasticsearch, or embedded Lucene — **Apache-2.0 licensed with no per-query or per-seat metering**.
- 🛡️ **Onyx (formerly Danswer)** represents the **premier open-source AI search application layer**, delivering **agentic RAG, deep research capabilities, multi-source enterprise connectors**, and native compatibility with both self-hosted LLMs (Ollama, vLLM) and commercial APIs.
- ⚡ **Meilisearch** and **Typesense** offer **instant search-as-you-type indexing with sub-50ms latency**, hybrid BM25/vector fusion, and seamless integrations with LangChain and MCP workflows.

## 🔓 Open-Source GitHub Projects

*Sorted by GitHub Stars Count (Descending)* 🌟

- **[Open WebUI](https://github.com/open-webui/open-webui)** [![Stars](https://img.shields.io/github/stars/open-webui/open-webui?style=social&color=white)](https://github.com/open-webui/open-webui/stargazers) 🔒  
  **Extensible, self-hosted AI & RAG web interface**, MIT licensed. Features document RAG, web RAG, persistent chat histories, prompt management, custom tooling/filters, and support for Ollama, vLLM, and OpenAI APIs.

- **[Elasticsearch](https://github.com/elastic/elasticsearch)** [![Stars](https://img.shields.io/github/stars/elastic/elasticsearch?style=social&color=white)](https://github.com/elastic/elasticsearch/stargazers) 🔍  
  **Distributed full-text & vector search engine**, Elastic License 2.0 / SSPL. The global standard for enterprise search, analytics, and hybrid lexical/vector retrieval powering thousands of search applications.

- **[Dify](https://github.com/langgenius/dify)** [![Stars](https://img.shields.io/github/stars/langgenius/dify?style=social&color=white)](https://github.com/langgenius/dify/stargazers) 🛠️  
  **Open-source LLM app development platform & RAG engine**, Innovation Open Source License. Includes visual workflow orchestrators, hybrid search engine connectors, vector indexing, agentic workflows, and prompt IDEs.

- **[Apache Superset](https://github.com/apache/superset)** [![Stars](https://img.shields.io/github/stars/apache/superset?style=social&color=white)](https://github.com/apache/superset/stargazers) 📊  
  **Modern data exploration & business insight platform**, Apache-2.0 licensed. Provides rich interactive visualization dashboards, SQL query engines, data search tools, and robust role-based access control.

- **[Meilisearch](https://github.com/meilisearch/meilisearch)** [![Stars](https://img.shields.io/github/stars/meilisearch/meilisearch?style=social&color=white)](https://github.com/meilisearch/meilisearch/stargazers) ⚡  
  **Lightning-fast search engine**, MIT licensed. Sub-50ms search-as-you-type latency, hybrid full-text/semantic search, typo tolerance, multi-tenancy, conversational search, and out-of-the-box MCP tool integration.

- **[RAGFlow](https://github.com/infiniflow/ragflow)** [![Stars](https://img.shields.io/github/stars/infiniflow/ragflow?style=social&color=white)](https://github.com/infiniflow/ragflow/stargazers) 📄  
  **Deep document understanding RAG engine**, Apache-2.0 licensed. Template-based document layout parsing, grounded citation generation, and pre-built enterprise connectors for unstructured file repositories.

- **[AnythingLLM](https://github.com/Mintplex-Labs/anything-llm)** [![Stars](https://img.shields.io/github/stars/Mintplex-Labs/anything-llm?style=social&color=white)](https://github.com/Mintplex-Labs/anything-llm/stargazers) 🖥️  
  **All-in-one desktop & server AI workspace**, MIT licensed. Turn documents, web pages, and databases into queryable insight engines with zero setup, full privacy, vector storage, and multi-user management.

- **[Milvus](https://github.com/milvus-io/milvus)** [![Stars](https://img.shields.io/github/stars/milvus-io/milvus?style=social&color=white)](https://github.com/milvus-io/milvus/stargazers) 🌌  
  **Open-source cloud-native vector database**, Apache-2.0 licensed. Engineered for trillion-scale vector search, high-throughput vector similarity retrieval, hybrid filtering, and scalable RAG backends.

- **[Qdrant](https://github.com/qdrant/qdrant)** [![Stars](https://img.shields.io/github/stars/qdrant/qdrant?style=social&color=white)](https://github.com/qdrant/qdrant/stargazers) 🦀  
  **High-performance Rust vector database & search engine**, Apache-2.0 licensed. Optimized for extended payload filtering, sparse-dense hybrid vector retrieval, payload quantization, and distributed cluster deployment.

- **[GraphRAG](https://github.com/microsoft/graphrag)** [![Stars](https://img.shields.io/github/stars/microsoft/graphrag?style=social&color=white)](https://github.com/microsoft/graphrag/stargazers) 🕸️  
  **Knowledge graph-driven RAG system by Microsoft**, MIT licensed. Combines LLM-generated knowledge graphs with vector retrieval for complex reasoning, multi-hop question answering, and dataset summarization.

- **[Typesense](https://github.com/typesense/typesense)** [![Stars](https://img.shields.io/github/stars/typesense/typesense?style=social&color=white)](https://github.com/typesense/typesense/stargazers) ⚡  
  **Fast, typo-tolerant open-source search engine**, GPL-3.0 licensed. Built in C++ for sub-50ms search performance, vector search, hybrid ranking, geo-search, and developer simplicity.

- **[LightRAG](https://github.com/HKUDS/LightRAG)** [![Stars](https://img.shields.io/github/stars/HKUDS/LightRAG?style=social&color=white)](https://github.com/HKUDS/LightRAG/stargazers) 💡  
  **Lightweight, fast Knowledge Graph RAG framework**, MIT licensed. Dual-level retrieval paradigm combining entity-relation graph extraction with fast semantic document retrieval for high-speed RAG tasks.

- **[Weaviate](https://github.com/weaviate/weaviate)** [![Stars](https://img.shields.io/github/stars/weaviate/weaviate?style=social&color=white)](https://github.com/weaviate/weaviate/stargazers) 🧠  
  **Open-source vector database**, BSD-3-Clause licensed. Horizontal scaling, multi-tenancy, cross-modal vector storage, hybrid keyword/vector search, and native modules for popular embedding models.

- **[OpenSearch](https://github.com/opensearch-project/OpenSearch)** [![Stars](https://img.shields.io/github/stars/opensearch-project/OpenSearch?style=social&color=white)](https://github.com/opensearch-project/OpenSearch/stargazers) 🏛️  
  **Community-driven search & analytics suite**, Apache-2.0 licensed. Linux Foundation project offering lexical search, vector database capabilities, log processing (Data Prepper), and OpenSearch Dashboards.

- **[Onyx](https://github.com/onyx-dot-app/onyx-foss)** [![Stars](https://img.shields.io/github/stars/onyx-dot-app/onyx-foss?style=social&color=white)](https://github.com/onyx-dot-app/onyx-foss/stargazers) 🎯  
  **Leading open-source enterprise AI search platform**, MIT licensed. Features agentic RAG, deep research capabilities, 50+ enterprise connectors, web search integration, role-based access controls, and code execution.

- **[Vespa](https://github.com/vespa-engine/vespa)** [![Stars](https://img.shields.io/github/stars/vespa-engine/vespa?style=social&color=white)](https://github.com/vespa-engine/vespa/stargazers) 🚀  
  **Open-source big data serving engine**, Apache-2.0 licensed. Powers real-time vector search, lexical matching, tensor evaluations, and complex multi-stage machine learning re-ranking at massive scale.

- **[Turing (Viglet)](https://github.com/openviglet/turing-ce)** [![Stars](https://img.shields.io/github/stars/openviglet/turing-ce?style=social&color=white)](https://github.com/openviglet/turing-ce/stargazers) 🌐  
  **Open-source enterprise search + generative AI platform**, Apache-2.0 licensed. Faceted semantic search, hybrid BM25+vector ranking, RAG chat with citations, AI agents, and MCP tools on Apache Solr, Elasticsearch, or embedded Lucene.

- **[Enterprise DocSearch RAG](https://github.com/maitraria15-dot/enterprise-docsearch-rag)** [![Stars](https://img.shields.io/github/stars/maitraria15-dot/enterprise-docsearch-rag?style=social&color=white)](https://github.com/maitraria15-dot/enterprise-docsearch-rag/stargazers) 🤖
